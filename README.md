# ds-beta

**非官方**的 DeepSeek 客户端复刻实验版（社会实验，非盈利）。与 DeepSeek 官方无关；DeepSeek 名称与标志归其权利人所有。

基于 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo)（MIT）。

- `web/` 前端（fork 自 chat-demo）
- `server/` Go + SQLite 后端：邀请码账号、多端同步、官方导出导入
- `android/` Capacitor 安卓壳
- `deploy/` docker compose
- `docs/` 架构与进度
